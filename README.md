# Грунт рядом

Карта объявлений «есть грунт / нужен грунт» по Москве и Московской области.

- `index.html` — страница: карта (Яндекс Карты), фильтры по типу и объёму, поиск, список и контакты с WhatsApp.
- `listings.json` — заявки, добавленные через вкладку «Добавить заявку».
- `server.py` — локальный сервер: пишет новые заявки в `listings.json` и отправляет их на GitHub. На опубликованном сайте список только читается, а добавленное там остаётся в браузере посетителя.
- Адреса ищет OpenStreetMap (Nominatim); если в `index.html` указан `YANDEX_API_KEY` — Яндекс.

## Запуск локально

```bash
python3 server.py
```

Затем откройте http://localhost:8765.
